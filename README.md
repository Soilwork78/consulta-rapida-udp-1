# Consulta Rápida ENF UDP — v2.1

Reconstrucción funcional basada en una nueva entrega empaquetada aparte de los archivos originales.

- `styles.css` separado de `index.html`
- visor de slides integrado por sesión
- banner de uso educativo
- service worker limitado a archivos reales
- endurecimiento del runtime para evitar fallas silenciosas
- misma identidad visual general del sitio original

## Uso
Abrir `index.html` en servidor estático o GitHub Pages.
